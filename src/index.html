Map Phone as Windows Network Drive

You can access your phone directly from Windows Explorer without this companion app if you prefer, by mapping it as a Network Drive over WebDAV.

Steps:

  1. Start the server on your Android phone via the app.
  2. Note the IP address and credentials shown on the phone screen.
  3. Open Windows Explorer > "This PC".
  4. Click "Map network drive" in the top ribbon (or "..." menu).
  5. Choose a drive letter and enter the phone's address (e.g. http://192.168.42.129:8080/).
  6. Check "Connect using different credentials".
  7. Click "Finish", then enter usbshare as the username and the password shown on your phone.

Windows WebDAV Basic Auth Fix

Windows by default refuses to send Basic Auth credentials over non-HTTPS connections. Since this works locally over USB, you must allow it by changing a registry key.

Run these exact commands in an Administrator PowerShell:

Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Services\WebClient\Parameters" -Name "BasicAuthLevel" -Value 2
Restart-Service WebClient
